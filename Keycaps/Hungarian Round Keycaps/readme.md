# 3D Printable Hungarian Typewriter Keycap Set

*Read this in [Hungarian / Magyarul olvasható itt](#magyar-verzió)*

This project contains fully 3D printable files and original CAD data for a custom mechanical keyboard keycap set, inspired by traditional typewriters.

## Features
- **Flat Typewriter Profile:** Circular top surface with a flat profile.
- **English & Hungarian Support:** Contains the standard English alphabet alongside all Hungarian accented characters (Á, É, Í, Ó, Ö, Ő, Ú, Ü, Ű). Simply print the subset of alphanumeric keys you need for your layout.
- **Extensive Key Support:** Beyond the alphas, the set includes standard modifiers (CTRL, ALT, ALTGR, TAB, ESC), a full F1-F16 row, and various utility/navigation keys (NAV, NUM, arrows, geometry symbols).
- **Multi-Color Optimized:** The legends have physical depth/height modeled in. This makes them perfect for dual-color printing.

## File Structure
- `/shapr3d` - Original Shapr3D workspace files.
- `/print_profiles` - 3MF files containing the configured slicer settings.

## Printing Guidelines
The exact print settings are embedded in the provided 3MF files. For reference, the key configurations are:
- **Nozzle:** 0.2 mm for great detail.
- **Layer Height:** 0.08 mm for smooth surfaces.
- **Orientation:** Face up.
- **Supports:** Minimal support to reduce filament waste and time spent on removing supports.

## Customization
The models were designed in Shapr3D. You can freely modify the designs within Shapr3D using the provided workspace files.

# 3D nyomtatható, magyar írógép stílusú keycap készlet

Ez a projekt egy egyedi, hagyományos írógépek ihlette, teljesen 3D nyomtatható keycap készlet fájljait tartalmazza.

## Jellemzők
- **Lapos írógép profil:** Kerek felső felület lapos profillal.
- **Angol és Magyar karakterkészletü:** Tartalmazza a standard angol ábécét, valamint az összes magyar ékezetes karaktert (Á, É, Í, Ó, Ö, Ő, Ú, Ü, Ű). Egyszerűen csak azokat az alfanumerikus gombokat kell kinyomtatnod, amelyekre a saját kiosztásodhoz szükséged van.
- **Bővített billentyűkészlet:** Az alfanumerikus gombokon túl a készlet tartalmazza a standard módosítókat (CTRL, ALT, ALTGR, TAB, ESC), egy teljes F1-F16 sort, valamint különböző funkció- és navigációs gombokat (NAV, NUM, nyilak, geometriai szimbólumok).
- **Többszínű nyomtatásra optimalizálva:** A feliratok fizikai mélységgel/magassággal rendelkeznek a modellen belül. Ez tökéletessé teszi őket a kétszínű nyomtatáshoz.

## Fájlok struktúrája
- `/shapr3d` - Az eredeti Shapr3D projektfájlok.
- `/print_profiles` - 3MF fájlok a beállított szeletelő (slicer) profilokkal.

## Nyomtatási javaslatok
A pontos nyomtatási beállításokat a mellékelt 3MF fájlok tartalmazzák. Referenciaként a legfontosabb paraméterek:
- **Fúvóka (Nozzle):** 0.2 mm a kiváló részletgazdagságért.
- **Rétegvastagság (Layer Height):** 0.08 mm a sima felületek érdekében.
- **Tájolás (Orientation):** Face up (felirattal felfelé).
- **Támaszték (Supports):** Minimális támaszték használata, amivel csökkenthető a filament hulladék és a támasztékok eltávolítására szánt idő.

## Tervezés és Modding
A modellek Shapr3D-ben készültek. A mellékelt projektfájlokkal a Shapr3D-n belül tetszőlegesen módosíthatók a modelleket.
